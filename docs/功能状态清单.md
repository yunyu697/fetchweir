> 复核人：项目维护者；每版执行人：本次发版的执行者（见 [发布检查清单](发布检查清单.md#0-功能状态清单复核发布闸门)）。

## 0. 状态口径

| 状态 | 定义 | 证据要求 |
| --- | --- | --- |
| 未实现 | 方案/界面写了，但代码路径不存在，或后端没有对应能力 | 写清缺的是界面、命令、参数还是数据 |
| 已实现未验证 | 代码存在且已接线，但没有可复核的实测证据，或证据已过期、环境不满足 | 写清缺哪条证据、为什么现在测不了 |
| 已实现已验证 | 有至少一条可复核证据，且能在当前版本复现 | 文档、截图、采样 JSON、CI 运行号四选一以上 |
| 产品边界 | 明确不做，不是缺口，不计入三态 | 写清边界与代码里的硬拒绝位置 |

证据规则：

- “代码里有”不算验证；必须有运行结果、截图、采样或 CI 记录。
- 状态只降不升：版本、站点、系统环境变化导致旧证据失效时，主动降为“已实现未验证”。
- 证据链接优先放在仓库内：文档 `docs/…`、截图 `docs/ui-shots/…`、采样 `docs/evidence/…`；CI 写运行号并附 GitHub Actions 链接。
- 本文件里的“优先级”只表示产品影响，不表示开发顺序：高 = 核心路径或首次使用被阻断；中 = 常见场景缺失或未验证；低 = 边缘/体验项。
- 表格里优先级为 `—` 的行是产品边界（DRM、锁定策略），不参与高/中/低排序。

## 4. 界面“未生效”控件逐项判定

全库检索 `未上线 / 敬请期待 / 即将 / 暂未 / 开发中 / coming soon`：**0 命中**。  
界面禁用项现在使用两种标签：“未生效” **15 处**（设置页 13 处、视频页 2 处），“暂不支持” **3 处**（设置页：全局连接上限、同时下载任务数、自动嗅探）；另有 1 处已启用项标注“下次启动生效”（启动后最小化到托盘）。  
“假控件”（可点击但没有任何行为）为 **0**：所有未接通控件都 `disabled`，并带 title 说明原因；锁定项另有“已锁定/自动”标签。

本轮已处理原 **5 处“做了没接线”**：

| 控件（位置） | 处理方式 | 实际做法 |
| --- | --- | --- |
| 启动后最小化到托盘（s1） | 接上了 | `Settings.start_minimized` 持久化；启动时跳过 `window.show()`，托盘仍可唤回窗口；界面标注“下次启动生效” |
| 全局连接上限（s2） | 改成不声称 | 后端只有自动全局预算（`base = 各活跃任务分段数之和`），没有手动上限字段；界面标“暂不支持”并写明实际行为 |
| 自动嗅探当前标签页（s4） | 改成不声称 | 扩展始终捕获，`autoCapture` 只读不用、没有可接的开关；界面标“暂不支持”并说明无法在应用内关闭 |
| 输出容器（视频页） | 接上了（仅合并路径） | `container` 参数经 `add_video_task` 传到 `--merge-output-format`（mp4/mkv）；直链与纯音频禁用并写明跟随源格式 |
| 进度条分段刻度（s6） | 接上了 | `TaskDto.segments` 下发真实边界，前端按 `end/total` 画线；删除原等距假刻度 CSS，不再假装真实分段 |

两处与事实不符的禁用文案已按实际行为改写：全局连接上限（实际有自动全局预算）、同时下载任务数（实际所有任务直接并发，没有全局队列）。

## 6. 必须长期跟踪的已知项

1. **YouTube 登录态**：Cookie 来源的界面、参数传递、缺失回退、错误引导已实测（离屏脚本 8/8）；但“配上可用 Cookie 后能解析成功并下载”从未验证成功。Chrome 因 App-Bound Encryption 报 `Failed to decrypt with DPAPI`；Edge 测试时被占用，未复测；Firefox 缺 `cookies.sqlite`。详见 [视频解析-Cookie来源.md](视频解析-Cookie来源.md)。
2. **平台产物**：当前只有 Windows x64。macOS 缺 arm64 ffmpeg 与公证凭据；Linux 安装路径未实测。历史 1.0.0 的 dmg/deb/AppImage 是当时 CI 产物，未验证，且当前流水线不再产出。详见 [发布检查清单](发布检查清单.md)。
3. **浏览器扩展**：只能手动“加载已解压”；Firefox Native Messaging 往返未联调；商店与 AMO 签名未配置。详见 [浏览器扩展分发.md](浏览器扩展分发.md)。
4. **安装包签名**：无代码签名，安装包 `NotSigned`，首次运行会触发 SmartScreen，需要用户点“更多信息 → 仍要运行”。详见 [README](../README.md)。
5. **悬浮条**：应用未运行时沿用上次落盘主题；换主题到悬浮条约 1s 生效（前端 60ms + 宿主 ≤700ms 轮询）。这是设计行为，不是缺陷。详见 [浏览器扩展分发.md](浏览器扩展分发.md)。
6. **自适应并发边界**：探测请求上的 429/503 不触发降档（`on_throttle()` 只挂在分段重试路径）；预算上限是各任务用户设定值之和，不是固定 32 条。详见 [perf/adaptive-conn.md](perf/adaptive-conn.md)。

# Fetchweir 1.0.2 发布说明

发布日期：2026-11-07。本版含 1.0.2 的追加修复，针对 1.0.0 安装后的实际反馈（卡顿、控制台弹窗、图标、扩展不可用、窗口拖不动）做修复，
不包含新功能。

## 修复内容

### 0. 1.0.2 追加修复（相对 1.0.1）

- 设置页扩展状态读错了后端字段名（`hostRegistered` / 实际是 `host_registered`），
  宿主已注册到 6 个浏览器却显示「未注册」；已修正。
- 进入设置页时重新拉取扩展状态；后台注册完成后立即失效状态缓存，避免启动竞态读到注册前的结果。

### 1. 启动与操作卡顿

- **根因一**：所有子进程（yt-dlp、reg、schtasks）没有 `CREATE_NO_WINDOW`，每次拉起都新建控制台窗口；
  启动期一次性写 6 次注册表、视频页每次进入都拉起 `yt-dlp --version`。
- **根因二**：`probe_video` 等 IPC 命令在主线程执行，前端每 100ms 逐条重排任务列表、每 2s 全表重建嗅探列表。
- **修复**：全部子进程走 `hidden_command`；IPC 命令改 `#[tauri::command(async)]`；注册表与解析器状态加缓存；
  进度渲染 200ms 合并；轮询改为单一 250ms 驱动器且按视图降频。

| 指标（同机热态，取多次中位数） | 1.0.0 | 1.0.1 |
| --- | --- | --- |
| 冷启动到可交互 | 18.9 s | 0.83 s |
| 启动期控制台窗口数 | 约 10 个 | 0 |
| 点击同步处理均值 | 1.29 ms | 1.17 ms |
| 点击后下一帧均值 | 29.1 ms | 19.7 ms |

### 2. 大量弹窗

- 弹窗就是上面说的控制台窗口，不是 UAC / 通知气泡；修复后任务栏不再出现任何应用相关控制台窗口。
- 正常启动不再自动请求 UAC：删除了「设置里开了管理员模式就每次启动提权」的逻辑，
  改为设置页显式「以管理员身份重启」按钮，点一次提权一次。
- 前端无 `alert` / `confirm` / 原生对话框；错误一律 toast + 状态区，不打断操作。

### 3. 设置页图标

- 侧栏「设置」图标由太阳图标替换为设计稿齿轮（`docs/evidence/settings-sidebar-dark.png`、
  `settings-sidebar-light.png` 为深浅主题实拍）。

### 4. 浏览器扩展可用性

- 扩展（`manifest.json` / `background.js` / `content.js`）随安装包落到资源目录 `extension/`，已用 7z 解包核对。
- Native Messaging 宿主注册在 **HKCU**，无需管理员；设置页显示「扩展文件是否随包 / 宿主已注册到哪些浏览器」。
- 设置 → 嗅探与浏览器 →「安装 / 管理」提供 4 步安装指引、打开扩展文件夹、复制安装步骤。
- 真实 Chromium（Edge headless）端到端 5/5：装扩展 → 浮动条出现 → 点击「在 Fetchweir 中打开」→
  最小化的窗口恢复并回到前台；唤起前后窗口枚举同一 hwnd、窗口数不变（未新建窗口）。

### 5. 窗口拖动

- 自绘标题栏补 `data-tauri-drag-region`（按钮以外的子元素），实测鼠标位移 (120,60) 窗口同步位移，
  双击标题栏最大化/还原生效。

### 6. 下载健壮性

- 探测请求由 1 次改为最多 3 次（700ms/1400ms 退避），避免瞬时 TLS 重置直接判失败。
- 分段重试上限 5 → 7；429/503 用 1.5s 起指数退避并按分段序号错开，减少同步重试造成的二次限流。

## 未验证 / 已知限制

1. **无 WebView2 Runtime 的干净机器**：本机已装 WebView2 Runtime，无法在不重装系统的前提下复现「干净环境」；
   已确认 CI 构建的 exe 不导入 `WebView2Loader.dll`（静态链接），安装包内无需再带该 DLL；
   缺失 Runtime 时的启动提示仍需在干净环境验证。
2. **源站限速下的并发策略**：同一 Wikimedia 文件用 8 连接会被 429 限速（105.7 s / 288 KB/s），
   2 连接为 12.3–31.3 s / 0.97–2.47 MB/s。当前版本只做退避重试，未实现按 429 自动降并发；
   建议遇到限速站点在设置里降低连接数。
3. **同名文件重复下载时的列表显示**：磁盘上会生成 `(1)` 后缀，但任务列表仍显示原文件名（不影响文件本身）。
4. 1.0.0 说明里列出的未验证项（注销重登触发计划任务、深色任务栏托盘、多用户、macOS 公证、Linux 安装、
   真实注销登录等）本版未变化。

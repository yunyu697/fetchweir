# 1.1.0

本版只做界面文案修正：把 5 处做不了的中优先级控件从「未生效」改成「暂不支持」，
并在 tooltip 里写明原因。功能行为与 1.0.10 完全一致，没有新增接口或下载逻辑改动。

版本号按 [版本号规则](版本号规则.md) 进位：1.0.10 的 patch 已到上限 10，再升 patch 得到 `1.1.0`。

## 界面变化

以下控件保持 `disabled`，不响应点击，只改标签与说明：

| 位置 | 控件 | 新标注 | 原因 |
| --- | --- | --- | --- |
| 视频页 | 下载字幕 | 暂不支持 | 解析器不返回字幕轨，本版本不做字幕下载 |
| 视频页 | 完成后校验 | 暂不支持 | 下载引擎不提供文件摘要 |
| 设置 → 下载 | 完成后校验 | 暂不支持 | 同上 |
| 设置 → 网络 | HTTP 代理 | 暂不支持 | 下载客户端未接入代理配置 |
| 设置 → 解析器 | 检查更新 | 暂不支持 | 解析器随安装包分发，无独立更新通道 |

功能状态清单同步为：「未生效」10 处（全部在设置页）、「暂不支持」8 处（设置页 6、视频页 2）、
可点击但无行为的“假控件”0 处。详见 [功能状态清单](功能状态清单.md#4-界面未生效控件逐项判定)。

## 本版实测

1.0.10 发布后在本机补测并留证（证据在 `docs/evidence/`）：

- 更新面板「取消下载 / 打开下载目录」：取消后回到可更新态、保留 `.part`；下载完成后能定位文件；
- 关闭窗口驻留托盘：`WM_CLOSE` 后主窗口隐藏、进程与托盘仍在；
- 管理员开关关闭：界面点击后后端与 `settings.json` 同步为关闭，不触发 UAC；
- 自定义更新源：不存在的仓库给出明确失败提示，恢复默认仓库后检查正常；
- 下载镜像：选 `ghfast` 后真实走镜像下载 926 B 资产，SHA256 与清单一致；
- 全局限速：设 1.2 MB/s 后平均 1.21 MB/s（不限速源对照约 56 MB/s）。

未验证：`gh-proxy.com` 前缀没有单独下载记录；更新中途断网/镜像失效的逐候选回退没有做。

## 平台与最低系统

- Windows 10 及以上，x64；提供当前用户 / 所有用户两种安装范围；
- 不自带 WebView2 运行时安装包，系统需已有 WebView2（Win10/11 通常自带）。

## 已知限制

与 [功能状态清单](功能状态清单.md#6-必须长期跟踪的已知项) 一致，重点：

- YouTube 登录态：Cookie 来源的界面与失败引导已实测，但“配上 Cookie 后解析成功并下载”仍未验证；
- 仅 Windows x64 产物；macOS 缺 arm64 ffmpeg 与公证凭据，Linux 安装路径未实测；
- 浏览器扩展只能手动“加载已解压”，Firefox Native Messaging 往返未联调；
- 安装包无 Authenticode 签名，首次运行会触发 SmartScreen，需手动放行。

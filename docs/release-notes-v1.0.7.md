# Fetchweir 1.0.7 发布说明

发布日期：2026-11-08

## 本版变更

### 品牌图标替换

- 新图标改为「入库 / 金库」语义：三层错位叠板 + 贯穿板面的向下箭头，替换此前的闸门轮廓。
- 程序图标（exe、安装包、任务栏、托盘、开始菜单/桌面快捷方式、卸载项）统一使用亮色版，
  `icon.ico` 含 16/20/24/32/48/64/128/256 八档。
- 16/20/24px 使用简化稿：两层板 + 实心填充箭头。标准稿的箭头描边在 16px 下只剩约 0.6px，
  直接缩放会糊成灰雾；简化稿在 16px 下仍保留紫板与浅色箭头两个独立形状。
- 界面标题栏 logo 随明暗主题切换：亮色主题用亮色版、暗色主题用暗色版；
  「跟随系统」时随系统实际外观变化即时切换，不只在手动点击时更新。
- 旧标准稿、单色稿与 `tray-dark.png` / `tray-light.png` 已删除，仓库内只保留一套新资源。

### 四套颜色主题，与明暗主题独立

- 新增紫罗兰（默认）、海蓝、森绿、暖砂四套完整配色，与 `light` / `dark` / `system`
  是两条独立的轴，可任意组合。
- 每套都定义完整 token：背景与标题栏、三级表面、三级文字、两级边框、强调色及悬停/按下/
  按钮文字色、成功/警告/失败/信息状态色、进度轨道与 4 个图表色。不是只改几个按钮。
- 强调色拆成两组：`--accent` 负责文字与图标，`--accent-solid` 系列负责实底主按钮（白字）。
  此前两者共用一种紫，暗色下无法同时满足按钮底够深、链接字够亮。
- 设置页「外观」新增独立的颜色主题选择器，与明暗主题分两行；点击即时全局生效。
  `colorTheme` 与 `theme` 分字段写入 `%APPDATA%\Fetchweir\settings.json`，互不覆盖，重启保持。

### 对比度实测

按 WCAG 2.1 逐套计算（正文/面板、次级文字、强调文字、主按钮渐变两端与悬停、状态徽标含 14% 底色），
八套组合均通过，最低项如下：

| 组合 | 最低项 | 比值 |
| --- | --- | --- |
| 紫罗兰 / 暗色 | 弱文字 / 面板 | 4.86 |
| 紫罗兰 / 亮色 | 弱文字 / 面板 | 4.82 |
| 海蓝 / 暗色 | 弱文字 / 面板 | 5.08 |
| 海蓝 / 亮色 | 弱文字 / 面板 | 4.66 |
| 森绿 / 暗色 | 弱文字 / 面板 | 5.24 |
| 森绿 / 亮色 | 弱文字 / 面板 | 4.78 |
| 暖砂 / 暗色 | 主按钮白字 / 渐变末 | 5.02 |
| 暖砂 / 亮色 | 强调文字 / 背景 | 4.85 |

正文/背景全部 ≥ 7:1，主按钮白字最低 5.02:1，暗色主题没有黑字黑底。

## 已知限制

- **浏览器扩展的悬浮条未纳入应用颜色主题。** 扩展图标文件已随本版换成新标，但网页内悬浮条
  仍使用它自己的固定配色，不随应用的明暗/颜色主题变化。
- 内容类型缩略图渐变与窗口关闭按钮的红色是固定装饰色，不随颜色主题走；其余界面表面均跟随 token。
- **安装包未做代码签名。** 新用户首次运行会触发 Windows SmartScreen，需点「更多信息」→「仍要运行」；
  请只从本仓库 Releases 页下载。
- **浏览器扩展需要手动加载。** 发布包不包含已安装的扩展，也没有一键安装入口；
  需解压扩展目录后，在 `chrome://extensions` 开启开发者模式，选择「加载已解压的扩展程序」。
- **CI 只构建 Windows x64。** macOS 缺 arm64 版 ffmpeg sidecar，且没有公证/签名流程；
  Linux 的 deb/AppImage 安装路径未实测。本版没有 dmg/deb/AppImage 产物。
- 不做 DRM / 付费墙 / 访问控制绕过；受保护流在解析阶段直接拒绝。

## 升级方式

- 1.0.6 → 1.0.7：覆盖安装即可，设置、颜色主题与任务记录都会保留。
- 1.0.5 及更早版本：覆盖安装即可；1.0.4 及更早版本此前没有任务落盘，升级后任务列表从空开始。
- 若本版 Release 未附带 `latest.json`，应用内「检查更新」不会发现 1.0.7，需要手动下载安装包。

## 主界面

已对齐：标题栏（品牌、引擎状态、主题、窗口按钮）、侧栏分组与计数、四张统计卡 2×2、筛选 chip、
任务表（名称/大小/速度/状态/操作，含进度条与分段信息）、底部状态栏、900×620 下侧栏收成图标列与统计卡 2×2。

差异（如实）：

1. 设计稿标题栏有通知铃铛，实现里没有：当前没有通知中心/消息源，按「不放假控件」的要求直接不画。
2. 设计稿第 4 张统计卡是「引擎内存」，实现同为「引擎内存」，但数值来源是宿主进程工作集
   （`K32GetProcessMemoryInfo`，3 秒刷新）。真实应用实测 41.4 MB（[app-main-live](ui-shots/app-main-live.png)）；
   `?demo` 页面没有宿主进程，数值显示「—」并注明「演示模式无宿主进程」，不填假数字。
3. 演示数据时间戳已调整为使进行中任务最新，首屏三条进行中与设计稿一致；排序仍按「添加时间」，
   表头可切换。此前排在前面的排队任务已下移。
4. 设计稿底部是预览工具条（视口/自适应），不属于产品界面；实现底部是真实状态栏（任务数、队列、总速率、版本）。

## 任务详情弹窗

已对齐：顶部速率/已下载/总大小/剩余时间四块、分段进度图、连接明细、引擎与写盘两组键值、操作按钮。

差异：

1. **连接明细的分连接速率改为「—」**。后端只上报任务总速率，没有分连接数据；此前按平均值铺 8 行属于编造，
   现在条形只表示任务总进度，并在行尾加说明「分连接速率与进度未上报」。
2. **分段进度图改为按总进度依次填满 16 列**，不再用「每列递减 1.2%」的假分布。
3. **校验行显示「未启用（后端无摘要接口）」**：下载完成没有做内容摘要，不写成「校验通过」。
4. 设计稿连接明细 5 行、引擎与写盘 8 行；实现按真实连接数（最多 16）与真实存在的键值渲染，行数随任务变化。

## 视频格式页

已对齐：左海报 + 右信息区、标题/域名/时长、chips、操作按钮组、格式表（分辨率/编码/帧率/容器/码率/体积/说明）、
视频/音频分页、DRM 行禁用并标「DRM 保护」、底部「加入队列」与输出目录。

差异：

1. 设计稿海报是真实缩略图；实现优先用解析器返回的 `thumbnail` 字段，没有时退化为渐变占位（演示数据无缩略图）。
2. 「下载字幕」保持禁用并标「未生效」：解析器（yt-dlp `-J`）当前不返回字幕轨清单。
3. 设计稿 chips 含「无 DRM / 字幕 12 种」；实现的「无 DRM / 协议 / 时长」来自解析器真实字段，字幕条数不展示。
4. 表头「体积」已按设计稿改名（原来是「大小」）。

## 资源嗅探页

已对齐：标签页信息卡、类型 chip 计数、体积/域名筛选、分组列表（流媒体/视频）、行内类型徽标与体积、
全选本组、底部批量条、加入下载。

差异：

1. 设计稿是「扩展在线 · 抓取 214 个请求」一行说明；实现是宿主状态卡（Native Messaging 端口、档位、最近抓取数）。
2. 设计稿有关键词/扩展名输入与「隐藏疑似」开关；实现的关键词在页头（文件名/域名），筛选条已补
   「全部格式」扩展名下拉（选项来自实际捕获的扩展名，真实生效）与「隐藏疑似重复」开关
   （按命中次数 > 1 过滤，真实生效）。
3. 设计稿行首是分辨率徽标（1080P/720P），实现是协议徽标（HLS/M3U8/MP4）；分辨率在视频页展示。

## 设置页

已对齐：左侧分区导航（常规/外观/下载引擎/网络/嗅探/视频解析/隐私与合规）、右侧分区卡片、
每行「标题 + 说明 + 右侧控件」、已自动保存提示、重置入口。

差异 / 设计稿之外新增：

1. 常规卡片新增「安装范围」只读行与「始终以管理员身份运行」开关（本轮新需求，设计稿没有）。
2. 提权开启时展示 UIPI 提示条（拖放被拦截，建议粘贴链接或走扩展）。
3. 右上角「导出配置」已实现：调 `export_settings` 写出 `fetchweir-settings-<时间戳>.json` 到设置的下载目录
   （目录不可用时落数据目录），并主动清空 `updateToken` 字段，避免把令牌写进普通文件。
   已实测一次：文件写出、字段解析正常、令牌为空，见「实测证据」。

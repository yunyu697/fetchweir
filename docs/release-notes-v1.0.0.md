# Fetchweir 1.0.0 发布说明

发布日期：2026-11-07。Windows x64 为主发布平台；macOS / Linux 产物由 CI 构建，见文末限制。

## 本版内容

- **下载引擎**：分段并发（默认 8 段，上限 16）、断点续传、全局限速、队列调度、失败重试与需处理状态。
- **界面**：全部任务 / 下载中 / 排队中 / 已完成 / 失败 / 分类 / 资源嗅探 / 视频下载 / 设置，五屏与设计稿对齐，
  统计卡含真实引擎内存（进程工作集）。
- **浏览器扩展**：Chrome MV3 + Native Messaging，三档嗅探（A 主动浮动条、B 徽标 + 右键、C 仅记录）。
- **视频解析**：yt-dlp sidecar，返回格式/编码/码率/体积；受保护流在解析阶段拒绝。
- **更新检查**：GitHub Releases + 三个前缀转发镜像，按安装范围选择对应安装包。
- **安装**：仅当前用户（默认，无需 UAC）与所有用户（Program Files，需 UAC）两种 NSIS 包。
- **Windows 集成**：自启动（Run / 计划任务）、始终以管理员身份运行、单实例参数转发、通知区托盘。
- **设置**：自动保存、配置导出（JSON，主动清空更新令牌）、安装范围与维护方式展示。

## 未验证（如实列出原因）

1. **真实注销 → 重新登录触发 `ONLOGON`**：需要结束当前桌面会话并重新登录，会中断发布流程；
   已验证触发器 XML 存在、`schtasks /Run` 手动拉起的是提权进程。
2. **深色任务栏下的通知区托盘实拍**：需要切换系统主题/任务栏配色并重启资源管理器；
   本轮只有默认主题实拍（`docs/ui-shots/tray-live-notification-area.png`）。
3. **多用户同时登录**：需要创建并同时登录第二个 Windows 账户；设计上数据各自在 `%APPDATA%`，未实测并发。
4. **macOS 公证**：无 Developer ID 证书、Apple 账号与 macOS 主机；CI 只产出未签名 dmg，首次打开需手动放行。
5. **Linux 系统级安装与发行版差异**：无 Linux 主机；CI 只构建 deb / AppImage，未验证依赖与托盘。
6. **提权开关的界面点击路径**：本轮用设置文件 + 提权命令完成开关效果核对，未通过界面点击复测。
7. **真实站点的视频解析**：只有本地样例；真实站点受网络与地域影响，未纳入自动验证。
8. **macOS / Linux 的更新安装动作**：只有代码路径，本机无对应环境。
9. **1.0.0「所有用户」包未重复实装**：该安装逻辑在 `1.0.0-alpha2` 构建上已完整实装/卸载，
   1.0.0 仅改版本号与更新器匹配，未重复占用前台执行 UAC 安装。

## 已知限制（界面已标注，不放假控件）

- 字幕轨下载、解析器独立更新检查未接通；顶部通知图标不渲染（无消息源）。
- 原生拖放导入未接通；提权状态下 Windows UIPI 会拦截拖入，界面建议粘贴链接或走扩展。
- 不同 Windows 用户会话之间不做跨用户单实例。

## 合规

- 不含任何 DRM / 付费墙绕过；受保护流直接拒绝。
- 全仓库按词边界检索禁用字样 `idm`：**0 命中**；宽松检索只有 2 处 `vidMeta` 标识符误命中（视频元信息字段，非产品名）。
